# Student Grade Calculator

A Python console application for the Week 2 control-flow and data-structures project.

## Project purpose
This program demonstrates:
- conditional logic with if/elif/else
- list management for storing student records
- for loops to process multiple students
- while loops for input validation
- try/except handling for user input errors
- class statistics for averages, highest, and lowest marks

## Files in this project
- `grade_calculator.py` – main program logic
- `test_grade_calculator.py` – unit tests for core functionality

## How to run
From the project folder, run:

```bash
py grade_calculator.py
```

## How to test
```bash
py -m unittest -v test_grade_calculator.py
```

## Example menu options
1. Add student records
2. Search student
3. Display results
4. Display class statistics
5. Exit
