# Student Grade Calculator

This project was created as part of the Week 2 practice task on control flow and data structures. It is a simple console application that collects student marks, calculates averages, assigns grades, and shows class statistics.

## Overview
The program demonstrates the main learning topics from the assignment:
- conditional logic using if/elif/else
- list handling for storing student data
- for loops for processing repeated input
- while loops for validation and repeated steps
- try/except blocks for safe user input handling
- summary calculations for class performance

## Project files
- `grade_calculator.py` – main application logic
- `test_grade_calculator.py` – basic validation tests for core functions
- `.gitignore` – ignores Python cache and editor-related files

## How to run
Open the project folder in a terminal and execute:

```bash
py grade_calculator.py
```

## How to test
Run the test file with:

```bash
py -m unittest -v test_grade_calculator.py
```

## Menu options
1. Add student records
2. Search for a student
3. Display all results
4. Display class statistics
5. Exit the program

## Notes
This is a practical project focused on using Python fundamentals in a realistic workflow. The app is intentionally simple, readable, and easy to extend if needed.
